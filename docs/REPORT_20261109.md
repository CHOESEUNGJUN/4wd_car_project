# 2026-11-09 작업 보고 (버전 C 실제 트랙 주행)

실제 2팀 코스(퍼즐 판 약 80cm, 테이프 1.9cm)에서 버전 C(`team2_bt_pid`)를 맞춘 날.
최종 코드는 GitHub 태그 `c-pid-done-20261109`.

## 최종 설정 (`team2_bt_pid.ino` 위쪽)

| 항목 | 값 |
|---|---|
| PID | KP 51 / KI 0.2 / KD 30, 기본 속도 BASE 120 |
| 코너 (끝 센서만 선을 봄) | 바깥 `CORNER_OUT` 180 / 안쪽 `CORNER_IN` −90 |
| 선 놓침 (센서 3개 모두 흰색) | PID 로 마지막 쪽 0.5초 보정 → 마지막 쪽으로 크게 0.5초 → 반대쪽 1초 → 정지 (`LOST_PID_MS` / `LOST_STOP_MS` / `BACK_SEARCH_MS`) |
| 장애물 (자동) | 10cm 안이면 정지, 약 0.3초 안 보이면 그 자리에서 다시 출발 (`AVOID_MM` 100, `CLEAR_COUNT` 5) |
| 수동 조종 | 전진·후진 100, 곡선 바깥 100, 제자리 회전 130 |

## 잘된 점

- **실제 트랙 정상 주행** : 출발 → 오른쪽 U 턴 → 안쪽 고리 → 합류 → 바깥 고리까지 버전 C 로 주행 확인.
- **선 놓쳤을 때 한쪽으로만 돌다 멈추던 문제 해결** : 원인은 센서 간격(4.9cm)이 테이프(1.9cm)보다 훨씬 넓은 것.
  코너를 돌다 넘치면 선이 반대쪽 센서 틈에 있는데, 예전 코드는 마지막으로 본 쪽으로만 1.5초 돌고 멈췄다.
  → 놓치자마자 돌지 않고 먼저 PID 로 보정, 그래도 없을 때만 마지막 쪽 → 반대쪽 순서로 찾게 바꿈.
- **배터리에 맞춘 코너 힘** : 새 배터리(전압 높음)에서 코너를 너무 크게 돌아 바깥 바퀴 220 → 180.
- **장애물 정지 후 재출발** : 선을 놓친 상태에서 장애물로 멈추면, 기다린 시간이 "선 놓친 시간"에 들어가 치우자마자 LOST 로 서던 문제를 고침. 정지 거리는 5cm → 10cm.
- **수동 조종 속도** : 새 배터리에서 너무 빨라서 차에서 직접 맞춤 (전진 130 → 100, 곡선 255 → 100, 제자리 230 → 130).
- **시뮬레이션에 실제 코스** : 코스 사진(옆에 둔 폰 16.5cm 로 크기 맞춤)으로 `sim/tracks/team2.png` 를 다시 그림 (바깥 71.5cm 둥근 정사각형). 센서 간격 4.9cm 실측값 반영.
- **버전 B** : 왼쪽 코너만 있는 트랙용 설정(`LEFT_CORNER_ONLY = 1`)이 켜져 있어 선을 놓치면 항상 왼쪽부터 찾던 것을 0 으로.

## 안된 점 (해 보고 되돌린 것, 남은 문제)

- **모든 꺾기를 좌우 반대 같은 힘(220 / −220)으로** : 미끄러운 판에서 헛도는 걸 막으려 했지만, 선을 놓치면 한 바퀴씩 돌아 버림 → 되돌림.
- **PID·코너에서 안쪽 바퀴를 절반·1/3 힘으로 뒤로** : 최소 힘 규칙(`MIN_PWM` 90) 때문에 1/3 이 실제로는 −90 이 되어 의미가 없었고, 처음 방식이 더 잘 달려서 되돌림.
- **센서 간격 4.9cm 는 그대로** : 센서가 고정이라 못 옮김. 선이 센서 사이 틈에 있으면 어느 쪽인지 알 수 없어서 코드로만은 한계가 있다 (시뮬 : 1.5cm 면 2바퀴 동안 선 놓침 2번, 4.9cm 면 수백 번).
- **시뮬이 실제와 안 맞음** :
  - 바닥 마찰계수를 미끄러운 퍼즐 판에 맞춘 적 없음 (마찰 0.5 와 0.2 에서 결과가 정반대).
  - 차 가운데 → 센서 거리를 사진으로 짐작(12cm)함.
  - 실제 차는 U 턴을 잘 도는데 시뮬은 안쪽 고리를 지름길로 빠지는 경우가 많고, 실제로 멈춘 곳(합류 후 첫 코너)도 시뮬에서는 재현이 안 됨.
  - 그래서 오늘 바꾼 값은 시뮬이 아니라 실제 차에서 정함.
- **배터리에 따라 달라짐** : 같은 PWM 값이라도 전압에 따라 회전량이 달라서, 새 배터리에 맞춘 값이 배터리가 약해지면 덜 돌 수 있다.
- **수동 곡선 회전** : 바깥 100 / 안쪽 80(최소 힘 때문에 실제로는 90)이라 좌우 차이가 작아 거의 직진처럼 갈 수 있음. 차에서 확인 필요.
- **디버그 앱 기록과 시뮬 비교(`--replay`)는 아직 실제 폰·차로 안 해 봄.**

## 앞으로 할 것

1. **실측해서 시뮬 맞추기** : 차 가운데(앞뒤 바퀴 축 사이) → 가운데 센서 거리, 앞뒤 바퀴 간격, 퍼즐 판에서 겨우 출발하는 PWM 과 배터리 전압 → `docs/SIM.md` 4장 방법으로 맞추기.
2. **실제 주행 기록** : `team2_bt_pid_debug` + "굴노 디버그" 앱으로 CSV 기록 → `python sim/track.py team2 --replay <CSV>` 로 어디서 선을 놓치는지 확인.
3. **배터리** : 대회 직전 충전 상태를 맞춰서 코너(`CORNER_OUT`)를 한 번 더 확인. 배터리가 약해져 덜 돌면 200~220.
4. **장애물** : 주행 중 10cm 정지가 부딪히지 않고 되는지, 치운 뒤 바로 다시 선을 따라가는지 확인.
5. **선 찾기** : 지금 방식으로 부족하면 좌우로 흔들며 찾기(짧게 한쪽 → 길게 반대쪽)를 시험.
6. **전원** : 아두이노 따로 9V, 모터 배터리 6개 (이전부터 남은 일).
7. **블루투스 정리 후 버전 D (ESP32-CAM 카메라로 선 인식)** : 센서 간격 문제를 카메라로 피할 수 있는지.
