## 1. 카메라 (브랜치 `extra/esp32cam`)

시작 : `cd ~/4wd_car_project && git switch extra/esp32cam` → ESP32-CAM 을 MB 보드에 꽂고, 아이폰 핫스팟 켜기 (호환성 최대화).
올리기 : `cd esp32/esp32cam_line && ~/.pio-venv/bin/pio run -t upload` (약 40초. Arduino IDE 로 올리면 안 됨). 자세한 건 브랜치의 `docs/CAMERA.md`, `docs/REPORT_20261111.md`.

- [ ] 카메라를 차 앞에 달기 (바닥을 약 45°). 웹 화면(`http://gulno-cam.local`)에서 테이프가 화면 가운데 점선을 따라 보이는지
- [ ] 실제 트랙에서 라인이 초록으로 잘 칠해지는지. 안 되면 코드의 `DARK_OFFSET`(지금 40) 조절. 어두운 색 물체를 라인으로 잡으면 채도(S) 조건 추가 (교안 3팀 HSV 방식)
- [ ] ESP32 에 새 펌웨어 올리기 (2026-11-12 컴파일만 확인 : 모폴로지 모드, 상태 줄 고정 버퍼, 메모리 안전장치) → 컬러에서 라인 확인 후 카메라 설정 "모폴로지"로 바꿔서 흰 바탕에 검정 라인이 깔끔하게 나오는지, 화면 갱신이 빨라지고 블루투스 조종 지연이 줄었는지 (모폴로지는 영상 대신 RLE 숫자로 그림)
- [ ] **30분 버티기 (메모리·속도·전원·열)** : 웹 화면을 열고 모폴로지 화면 + 카메라 주행 + 신호등 인식을 켠 채 30분. 한 번에 4가지를 봄
  - 메모리 : 시리얼 `I,heap,<남은 내부 메모리>,...` 이 계속 줄면 누수, 오르내리며 일정하면 정상. `I,restart,low_heap` 이 나오면 메모리 부족으로 스스로 재시작한 것
  - 속도 : 웹 화면 fps (모폴로지 화면 기준). 판단은 ESP 안에서 0.15초마다
  - 전원 : 주행 중 ESP 가 재시작하는지 (시리얼에 부팅 글자가 다시 나오면 전압이 떨어진 것 -> 5V 외부 전원 따로, 모터 배터리와 나누기)
  - 열 : 끝나고 ESP32-CAM 을 만져 봄. 너무 뜨거우면 전면 LED `FLASH_DUTY`(30) 낮추기
  - 다 되면 남는 시간은 다른 것
- [ ] 웹 화면에서 HC-06 연결 → 조종 버튼으로 차가 움직이는지 (폰 굴노 앱은 HC-06 에서 끊기)
- [ ] **카메라로 주행 1단계 (만들어 둠, 2026-11-12 컴파일만 확인)** : 차에 **버전 D** `team2_bt_cam` 올리기 (Arduino IDE, 브랜치 `extra/esp32cam`. 카메라 주행할 때) + ESP32 새 펌웨어 올리기 (PlatformIO). 웹 화면에서 카메라 설정 "모폴로지" → "카메라 주행" 버튼. ESP32 가 판단을 대문자 `G`(직진) `L`/`R`(살짝) `Q`/`W`(크게)로 0.15초마다 보냄 (자동 주행 속도). 판단 기준 `CAM_SOFT`(20) `CAM_HARD`(50) 조절. 화면을 닫거나 조종 버튼을 누르면 멈춤
- [ ] **카메라로 주행 2단계** : 아두이노(버전 C)에 카메라 자동 모드 `c` 추가 (ESP32 가 라인 위치를 `#E-35` 처럼 초당 약 20번 보내고, 아두이노 PID 가 그 값으로 주행. 0.2초 넘게 안 오면 라인센서로 / 정지). 웹 화면에 "라인센서 자동" / "카메라 자동" 버튼, `PROTOCOL.md` 에 `c`, `#E` 추가
- [ ] **신호등 인식 (만들어 둠, 2026-11-12 컴파일·가짜 사진 시험만)** : 브랜치의 아이폰 앱 굴노를 다시 올려서 "신호등 화면" (초록 → 노랑 → 빨강) 을 카메라 앞 위쪽에 두고, 웹 화면 "신호등 인식" 켜기 → 세 색이 바로 잡히는지. 카메라 주행·라인센서 주행에서 빨강 = 정지, 초록 = 다시 주행, 노랑 = 서행 (버전 D `SLOW_BASE` 100, 출발 못 하면 올림). 안 잡히면 `SIG_Y1`(54), `SIG_MIN`(40), 색 기준 조절. 거리·밝기별 성공 횟수 기록 (교안 3팀 STEP 9)
- [ ] 라인센서 자동과 카메라 자동 비교 (한 바퀴 시간, 선 놓침 횟수)
- [ ] **교안 2팀 심화 B (47쪽)** : 차를 보지 않고 영상만 보며 조종, 영상 지연이 몇 ms 인지 재기 (4팀 STEP 6 스톱워치 촬영법)
- [ ] 느린 원인 가려내기 : 블루투스 끈 / 켠 상태 ping, 영상 띄움 / 닫음 조종 반응, 핫스팟 / 공유기 비교
- [ ] (나중) 인식이 믿을 만해지면 영상은 끄고 테슬라식 화면 : 인식 결과(줄마다 라인 양 끝, 향할 곳)만 보내 브라우저가 그리기 + "사진 한 장" 버튼
