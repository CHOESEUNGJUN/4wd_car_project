# 카메라(ESP32-CAM) 라인 인식 · 카메라 주행 · 신호등 — ESP32 펌웨어 + 아두이노 버전 D

> 이 브랜치(`extra/esp32cam`)의 추가 프로젝트. 작업 보고 : [`REPORT_20261111.md`](REPORT_20261111.md) · 다음에 할 일 : `main` 의 [`NEXT.md`](https://github.com/CHOESEUNGJUN/4wd_car_project/blob/main/docs/NEXT.md)

라인센서 3개 대신 ESP32-CAM 카메라로 선을 본다. 센서 3개는 오차가 −3 ~ +3 일곱 칸뿐이지만,
카메라는 선 위치를 **−100 ~ +100 연속값**으로 주고, 화면 위쪽(먼 곳)으로 **커브를 미리** 본다. 같은 사진의 위쪽으로 **신호등 색**도 본다.

교안 4팀은 PC 파이썬(OpenCV)이 영상을 받아 판단하고 PC 블루투스로 차에 `g`/`s` 를 보낸다.
우리는 **ESP32 안에서 바로** 보고 판단해서 블루투스로 보낸다 (PC 없음, 영상 전송·PC 처리 지연 없음). 웹 화면은 보기·조종용.

| 파일 | 어디에 올림 |
|---|---|
| `esp32/esp32cam_line/` (`esp32cam_line.ino`, 웹 화면 `page.h`, `platformio.ini`, `huge_app.csv`) | ESP32-CAM (AI Thinker) : **PlatformIO** |
| `arduino/team2_bt_cam/team2_bt_cam.ino` | 아두이노 UNO : **버전 D** = 버전 C + 카메라 주행 글자 `G L R Q W` + 신호등 글자 `x v n` : Arduino IDE |
| `arduino/motor_control_low_frequency_cam/` | 아두이노 UNO : **버전 D + 저주파 PWM** (시험용, 약 122Hz, 배선 4개 맞바꿈 ENA 9 · IN2 5 · ENB 10 · IN3 6). 안 좋으면 선 되돌리고 버전 D : Arduino IDE |
| `apps/ios_mac/` | 아이폰 앱 굴노 : **"신호등 화면"** (폰을 신호등으로) : Xcode |

## 0. ESP32-CAM 다루기 (매번 이 순서)

처음 한 번은 4장(올리기)과 5장(와이파이)을 먼저. 그다음부터는 이것만.

1. **핫스팟 켜기** : 아이폰 개인용 핫스팟 (**호환성 최대화** 켬). 노트북·폰도 이 핫스팟에 연결.
2. **차 켜기** : 아두이노(버전 D) 전원 → HC-06 빨간 LED 깜빡 (아직 아무도 안 붙음).
3. **ESP32-CAM 켜기** : 5V 외부 전원. 앞 흰 LED 가 깜빡이다가 핫스팟에 붙으면 **계속 켜짐** (뒤 빨간 LED 도 켜짐).
4. **웹 열기** : 브라우저로 **http://gulno-cam.local** → 위 배지 "카메라" 가 초록이면 연결.
5. **차 블루투스 연결** : 블루투스 칸 **연결** (처음이면 **기기 찾기** → 목록에서 차 HC-06, PIN 1234). 켤 때마다 한 번 눌러야 함 (자동으로 붙지 않음). 붙는 동안 앞 LED 깜빡 → 붙으면 계속 켜짐, HC-06 LED 도 계속 켜짐, 배지 "차 블루투스" 초록, 차 상태 칸에 숫자가 나옴.
6. **주행 고르기** (2장) :
   - **라인센서 주행** : 차를 선 위에 두고 누름. 0.5초 서 있다가 출발.
   - **카메라 주행** : 카메라 설정 **모폴로지** 를 켠 뒤 누름 (확인 창 → 확인).
   - 멈출 때 : **정지 · 수동** (또는 스페이스, ■).
7. **신호등** (필요할 때) : **신호등 인식 : 켬** → 아이폰 굴노 앱 **신호등 화면** 을 카메라 앞 위쪽에. 웹 배지에 지금 신호가 나옴.
8. **끝낼 때** : 정지 · 수동 → 블루투스 **끊기** (폰 앱으로 차를 쓰려면 꼭) → 전원 끄기. 웹 화면만 닫아도 차는 몇 초 안에 멈춘다 (카메라 주행 2.5초, 라인센서 주행 5초 : 연결 신호 `h` 가 끊겨서).

### LED 보는 법

| LED | 상태 | 뜻 |
|---|---|---|
| 앞 흰색 (플래시) | 깜빡 (0.4초) | 연결 중 : 설정 모드, 핫스팟 붙는 중, 블루투스 붙는 중 |
| | 계속 켜짐 (약하게) | 다 연결됨 (바닥 비춤) |
| 뒤 작은 빨강 | 천천히 깜빡 (0.5초) | **설정 모드** (설정용 와이파이 `GULNO-CAM-SETUP-xxxx` 켜짐) |
| | 계속 켜짐 | 핫스팟에 붙음 |
| | 빠르게 깜빡 | 핫스팟에 붙었다가 끊김 (핫스팟 확인) |
| | 꺼짐 | 전원 없음, 또는 시작 중 |

### 시리얼 모니터로 보기 (USB, 9600)

ESP32-CAM-MB 에 꽂고 `~/.pio-venv/bin/pio device monitor` (또는 Arduino IDE 시리얼 모니터 9600). 10초마다 안내 줄이 나온다.

| 줄 | 뜻 |
|---|---|
| `I,ip,<주소>,gulno-cam.local` | 핫스팟에 붙음. 주소로도 열 수 있음 |
| `I,setup,<설정용 와이파이>,<암호>` | 설정 모드. 이 와이파이에 폰으로 붙어 핫스팟을 넣기 (5장) |
| `I,fail,<핫스팟>,<이유>` | 저장된 핫스팟에 못 붙은 이유 (못 찾음 / 5GHz / 암호 틀림) |
| `I,joined,<핫스팟>` | 설정 모드 중에 핫스팟이 나타나서 붙음 → 다시 시작 |
| `I,heap,<남은 내부>,<가장 큰 덩어리>,psram,<전체>,<남은>` | 메모리. 30분 동안 계속 줄면 누수 |
| `I,restart,low_heap` | 메모리가 모자라 스스로 다시 시작함 |
| `E,camera` | 카메라를 못 찾음 → 리본 케이블 다시 꽂기 |

## 1. 구조

```
 5V 외부 전원 ──▶ ESP32-CAM (OV2640 컬러, 160x120)
                   ├ 아래쪽 : 검은 라인을 따라가며 찾음 → 위치 −100~100, 직진 / 좌 / 우 판단
                   ├ 위쪽   : 신호등 색 (빨강 / 초록 / 노랑)
                   ├ 와이파이 (내 핫스팟) ──▶ 폰·노트북 브라우저 http://gulno-cam.local
                   │      영상 또는 모폴로지 화면, 선 판단, 차 상태, 주행 버튼, 조종, 블루투스 기기 목록
                   └ 블루투스 ──▶ HC-06 ──▶ 아두이노 (버전 D)
                          보냄 : 조종 g b l r q w s a m h, 카메라 주행 G L R Q W, 신호등 x v n (0.2초마다)
                          받음 : 차 상태 줄 "ar,23,011,LINE,1,60" → 화면에 표시
```

- ESP32-CAM 은 **5V 외부 전원**으로 따로 켜고, 아두이노와는 **블루투스로만** 주고받는다 (선 없음).
- 웹 서버 하나(포트 80)가 화면·조종·영상을 다 한다. 영상은 2개 화면까지 동시에.
- SD카드는 필요 없다 (사진은 판단하고 바로 버림).

## 2. 주행 모드

웹 화면의 버튼으로 고른다. 신호등 인식은 두 주행 어디에나 켜고 끌 수 있다 (2 × 켬/끔).

| 버튼 | 누가 판단 | 하는 일 |
|---|---|---|
| **라인센서 주행** | 아두이노 (버전 C·D 같음) | ESP32 가 `a` 를 보냄 → 차가 라인센서 3개 + PID 로 스스로 달림 |
| **카메라 주행** | ESP32 | 모폴로지 화면 + 차 블루투스 연결일 때만. `m` 을 보낸 뒤 0.15초마다 위치를 글자로 : ±`CAM_SOFT`(20) 안 = `G` 직진, ±`CAM_HARD`(50) 안 = `L`/`R` 살짝, 그 밖 = `Q`/`W` 크게. 버전 D 는 이 글자를 수동 조종처럼 받되 **속도는 자동 주행과 같음** (`BASE` 120, `L`/`R` = BASE∓KP, `Q`/`W` = 코너 180/−90). 라인이 0.3초 넘게 안 보이거나, 화면을 닫거나, 사람이 조종 버튼을 누르면 멈춤 |
| **정지·수동** | 사람 | 카메라 주행을 끄고 `m`. 조종 버튼·키보드로 움직임 |
| **신호등 인식** (켬/끔) | ESP32 가 색을 보고, 차가 따름 | 지금 신호를 0.2초마다 계속 보냄 (아래 표). 웹 화면에 지금 본 신호 표시 |

| 신호 | 보내는 글자 | 라인센서 주행 (자동 모드 그대로) | 카메라 주행 |
|---|---|---|---|
| 🔴 빨강 | `x` | 장애물처럼 서서 기다림 (단계 `RED`) | `G L R Q W` 를 받아도 멈춤 |
| 🟡 노랑 = 서행 | `v` | 기본 속도 `BASE` 120 → `SLOW_BASE` 100 으로 라인 추종 | `G L R` 가 느려짐 |
| 🟢 초록 / 신호 없음 | `n` | 보통 (빨강에서 바뀌면 그 자리에서 다시 라인 추종) | 보통 |

- **라인은 차가 라인센서로 계속 보고, 신호만 카메라가 준다** (두 가지를 동시에). 모드(자동/수동)는 신호 때문에 바뀌지 않는다.
- **한 번이 아니라 계속 보냄** : ESP32 가 0.2초마다 (2초면 10번) 지금 신호 글자를 보내고, 차는 같은 글자가 오는 동안 그 상태를 유지. 몇 개 놓쳐도 그대로. 노랑은 `SIG_HOLD_MS`(1초) 넘게 안 오면 보통으로 본다. **빨강은 시간으로 안 풀린다** : 다른 신호 글자가 오거나 사람이 `a`/`m` 을 보낼 때까지 서 있음 (ESP32 가 꺼져도 안 달림). 신호등 인식을 끄면 ESP32 가 `n` 을 3번 보내 풀어 준다. 교안 4팀이 `g`/`s` 를 계속 보내는 것과 같은 생각.
- 코너(`Q`/`W`, CORNER_OUT/IN)는 힘이 필요해서 서행에서도 그대로. 사람 조종(소문자)은 신호와 상관없이 그대로.
- 버전 C 는 `G L R Q W x v n` 을 무시한다 (카메라 주행·신호등은 버전 D 만).
- 빨강에서 멈춘 채 ESP32 가 꺼졌다면 : 폰 앱이나 웹으로 `m`(수동) 또는 `a`(자동)를 보내면 풀린다 (모드를 고르면 신호 초기화).

### 신호등 (아이폰 앱)

아이폰 앱 굴노 아래쪽 **"신호등 화면"** 버튼 (차 연결 없이 됨). 화면 전체가 **초록 → 노랑 → 빨강** (순수 #00ff00 / #ffff00 / #ff0000).
누르면 다음 색, 아래 `자동 n초` 로 저절로 바뀌는 간격 (0 = 끔). 켜져 있는 동안 밝기 최대, 화면 안 꺼짐.
폰을 카메라 앞 **위쪽**(화면 위 45% 안)에 둔다.

인식 : 사진 위쪽(`SIG_Y1` 54줄)에서 2칸마다 색을 봐서 빨강(R≥160, G·B≤80), 초록(G≥150, R≤110, B≤150), 노랑(R≥160, G≥150, B≤100) 중
가장 많은 색이 `SIG_MIN`(40)개 넘게, **3장 연속**이면 신호. 색 기준은 실제 화면으로 재서 맞춘다.
노랑이 하얗게 날아가거나 바닥과 헷갈리면 파랑(가장 잘 구분됨)이나 주황(빨강과 가까움)으로 바꾸는 것을 검토.

## 3. 배선

| ESP32-CAM | 연결 |
|---|---|
| 5V | **따로 5V** (보조배터리 USB, 또는 5V 강압 모듈). 와이파이·블루투스·카메라·LED 가 순간 0.5A 넘게 먹어서 아두이노 5V 로는 부족. 모터 배터리와 같이 쓰면 출발할 때 전압이 떨어져 ESP 가 재시작할 수 있음 |
| GND | 5V 전원 GND |

아두이노와 선은 잇지 않는다 (블루투스로 통신). 업로드할 때는 ESP32-CAM-MB 받침 보드에 꽂는다.

## 4. 올리기

### ESP32-CAM (PlatformIO)

**Arduino IDE 로 올리면 안 된다** (예전 라이브러리로 빌드돼서 블루투스를 켜면 메모리 부족으로 멈춤).

1. 처음 한 번 : `python3 -m venv ~/.pio-venv && ~/.pio-venv/bin/pip install platformio`
2. ESP32-CAM 을 **ESP32-CAM-MB** 받침 보드에 꽂고 USB 연결.
3. 올리기 : `cd esp32/esp32cam_line && ~/.pio-venv/bin/pio run -t upload` (포트를 못 찾으면 `--upload-port /dev/cu.usbserial-xxxx`)
4. 시리얼 : `~/.pio-venv/bin/pio device monitor` (나가기 Ctrl+C)

- 처음 빌드는 ESP32 라이브러리를 `platformio.ini` 설정으로 다시 만드느라 약 2GB 를 받고 20~40분. 그다음부터는 1분 안팎.
- 처음 빌드가 `IncompatiblePlatform ... v6.2.0-post.1` 로 멈추면 같은 명령을 한 번 더 (pioarduino 버전 판단 문제).
- "Failed to connect" 면 MB 보드 IO0 버튼을 누른 채 RST → 떼고 다시.

### 차 (버전 D, Arduino IDE)

`arduino/team2_bt_cam/team2_bt_cam.ino` 를 열고 보드 Arduino UNO 로 업로드. 핀·PID 값은 버전 C 와 같다.

저주파 PWM 시험 : `arduino/motor_control_low_frequency_cam/` (버전 D 와 같고 모터 PWM 만 약 122Hz). **먼저 배선 4개를 맞바꿈** (L298N ENA 선 5 → 9, IN2 선 9 → 5, ENB 선 6 → 10, IN3 선 10 → 6), 바퀴를 띄우고 방향부터 확인. 되돌릴 때는 선을 되돌리고 버전 D. 이유·비교 : `docs/PID.md` 끝

### 아이폰 앱 (Xcode)

`apps/ios_mac/MiniCar.xcodeproj` → Signing 에서 내 Apple ID 팀 → 아이폰 연결 → ▶ (`apps/README.md`).

## 5. 와이파이 연결 (프린터처럼)

핫스팟 이름·암호는 **코드에 적지 않는다** (공개 저장소). 처음 한 번 폰으로 넣어 주면 ESP32 안에 저장된다.

1. 연결할 와이파이를 켠다 — 폰 핫스팟이면 **2.4GHz** (아이폰 : 설정 → 개인용 핫스팟 → **호환성 최대화** 켜기).
2. ESP32-CAM 을 켠다. 저장된 핫스팟이 없거나 15초 안에 못 찾으면 **설정 모드** : 설정용 와이파이 `GULNO-CAM-SETUP-xxxx` 가 켜진다.
3. 설정용 와이파이 암호는 처음 켤 때 무작위 8글자로 만들어 저장한다. **USB 로 꽂고 시리얼 모니터(9600)** 를 열면
   `I,setup,GULNO-CAM-SETUP-xxxx,<암호>` 가 10초마다 나온다. 종이에 적어 두면 프린터 스티커처럼 계속 쓴다.
4. 폰에서 그 와이파이에 접속 → 설정 화면이 자동으로 뜬다 (안 뜨면 http://192.168.4.1).
5. 핫스팟 이름(목록에서 고름)과 암호를 넣고 **저장하고 연결** → 다시 켜지며 그 핫스팟에 붙고, 설정용 와이파이는 꺼진다.
6. 폰·노트북도 그 핫스팟으로 돌아가서 **http://gulno-cam.local** (안 되면 시리얼의 `I,ip,<주소>`).

- 다음부터는 켜면 바로 붙는다. 핫스팟을 바꾸려면 그 핫스팟을 끈 채로 켜면 설정 모드.
- 못 붙어 설정 모드가 돼도 저장된 핫스팟을 10초마다 다시 찾는다. 못 붙은 이유는 시리얼 `I,fail,<핫스팟>,<이유>` 와 설정 화면에.
- 아이폰 핫스팟은 맥에 IPv6 만 주기도 한다 (맥 주소가 `192.0.0.2`). ESP32 도 IPv6 를 켜 두었으니 맥에서는 **http://gulno-cam.local** 로 연다 (172.20.10.x 숫자 주소로는 안 열릴 수 있음).

## 6. 웹 화면 (http://gulno-cam.local)

노트북은 두 칸(왼쪽 영상, 오른쪽 조종·상태), 폰은 한 줄로 아래로 이어진다.

| 칸 | 내용 |
|---|---|
| 위 배지 | 카메라 연결 / 차 블루투스 연결 / 초당 장수 (fps) |
| 영상 | **컬러** : 실제 사진 위에 초록 = 인식한 라인, 노란 점 = 라인 가운데 경로, 빨간 선·점 = 향할 곳, 흰 점선 = 차 가운데. **모폴로지** : 흰 바탕에 정리된 검정 라인만. 왼쪽 위에 판단 (⬆ 직진, ⬅ 좌, ➡ 우, ✕ 선 없음, ╋ 교차선) |
| 주행 | **라인센서 주행** / **카메라 주행** / **정지·수동** / **신호등 인식 켬·끔** + 지금 신호 (2장) |
| 조종 | ▲ ▼ ◀ ▶ ↺ ↻ ■. 노트북은 방향키, Q·E 제자리, 스페이스 정지 (앱과 같은 규칙 : 누르는 동안 0.2초마다, 떼면 `s` 두 번) |
| 차 상태 | 아두이노 상태 줄을 풀어서 : 모드, 동작, 앞 거리, 라인센서 ○●○, 단계, 오차 / 보정 |
| 블루투스 | **기기 찾기** (약 5초) → 목록(이름 · 주소 · 신호)에서 차를 누르면 연결 (PIN 1234). 고른 기기는 저장돼서 다음엔 **연결** 만. **끊기** 하면 폰 앱이 HC-06 을 쓸 수 있다 |
| 카메라 설정 | 좌우 반전 (이 보드는 기본 켬) / 위아래 뒤집기 / **모폴로지**. 바꾸면 바로 적용·저장 (재시작 없음) |

- **컬러 vs 모폴로지** : 카메라는 늘 컬러로 찍는다 (신호등 색 때문에). 화면만 다르다. 컬러 = 테스트용 (JPEG 영상). 모폴로지 = 라인 확인 후 주행용 : 영상 대신 마스크를 줄마다 검정 구간(RLE)으로 웹소켓에 초당 10번, 한 번에 약 500바이트 (컬러 JPEG 의 약 1/7). 카메라 주행은 모폴로지 화면에서만 켜진다.
- **주고받기는 웹소켓 하나** (`/ws`) : 조종 글자는 바로 (화면 → ESP32 → 블루투스 → 차), 판단·차 상태는 ESP32 가 0.2초마다 밀어 준다. 화면이 열려 있는 동안 ESP32 가 차에 연결 신호 `h` 를 0.6초마다 대신 보낸다 (화면을 닫으면 끊겨서 자동 주행이 멈춤).
- HC-06 은 한 번에 한 기기만 붙는다. ESP32 가 붙어 있으면 폰 굴노 앱은 블루투스로 못 붙는다 (신호등 화면은 블루투스 없이 됨).
- LED : 앞 흰색 플래시는 연결 중(설정 모드, 핫스팟·블루투스 연결 중) 깜빡, 다 연결되면 계속 켜짐 (바닥 비춤, 밝기 `FLASH_DUTY` 30/255). 뒤 빨간 LED 는 와이파이 상태 (설정 모드 깜빡, 연결 켜짐).

## 7. 영상 처리 (전처리)

1. 컬러(RGB565) 사진 160x120 → 밝기 (R 30% G 59% B 11%)
2. **이진화** : 줄마다 평균보다 `DARK_OFFSET`(40) 어두우면 라인 후보 (바닥이 완전히 흰색이 아니어도 테이프보다 밝으면 됨)
3. **모폴로지 열림** : 3x3 침식으로 작은 점·가는 잡음을 지우고, 3x3 팽창으로 라인 굵기를 되돌림
4. **라인 추적** : 화면 아래부터 이어지는 검정 덩어리만 따라감 (한 줄에 `MAX_JUMP` 18칸 넘게 튀면 다른 물체). 카메라 주행은 가까운 곳과 `LOOK_Y`(42) 줄의 먼 곳을 7 : 3 으로 섞어 위치 −100~100
5. **신호등** : 같은 컬러 사진의 위쪽에서 색 범위 (2장)

## 8. 메모리

- Arduino IDE 용 ESP32 라이브러리로는 블루투스 클래식 + 와이파이 + 카메라를 같이 켤 내부 메모리(약 320KB)가 없다. 그래서 **PlatformIO 로 라이브러리를 다시 빌드**해서 블루투스·와이파이 메모리를 외부 메모리(PSRAM 4MB)에 먼저 두고, BLE 는 끈다 (`platformio.ini`). 블루투스를 켜도 내부 메모리가 20~40KB 남는다 (2026-11-11 시험).
- 사진·마스크 버퍼는 전부 PSRAM. 상태·명령은 고정 크기 버퍼 (메모리를 잡았다 놓았다 하지 않음). 실행 중에 카메라를 껐다 켜지 않음. 블루투스는 "기기 찾기"·"연결"을 누를 때 켬. 여러 작업이 같이 쓰는 것은 잠금(mutex)으로.
- 안전장치 : 남은 내부 메모리가 `HEAP_MIN`(12KB)보다 적은 상태가 5초 이어지면 스스로 재시작 (핫스팟·블루투스는 저장돼 있어 다시 붙음). 시리얼 `I,heap,<남은>,<가장 큰 덩어리>` 가 계속 줄면 누수.
- 빌드 (2026-11-12) : RAM 24%, Flash 50%. 버전 D : UNO RAM 24% (497 / 2048 바이트).

## 9. 카메라 달기와 맞추기

- 차 앞쪽에 **비스듬히 아래**(약 45도). 화면 **아래쪽에 차 바로 앞 테이프**, **위쪽 1/3 쯤에 10~20cm 앞 테이프**가 오게. 거꾸로면 좌우 반전 / 위아래 뒤집기.

1. 같은 핫스팟의 브라우저에서 **http://gulno-cam.local**.
2. 컬러 화면에서 테이프가 초록으로 칠해지는지, 노란 점이 가운데를 따라가는지, 빨간 점이 앞쪽 라인 위에 있는지.
3. 바닥 무늬까지 잡거나 테이프를 못 잡으면 `DARK_OFFSET` 조절 (클수록 더 어두워야 라인).
4. "모폴로지"로 바꿔 흰 바탕에 검정 라인만 깔끔한지.
5. 차에 **버전 D** 를 올리고 "카메라 주행". 너무 흔들리면 `CAM_SOFT` 를 키우고, 커브에서 덜 꺾으면 `CAM_HARD` 를 줄임.
6. 신호등 인식을 켜고 아이폰 신호등 화면으로 세 색이 잡히는지. 안 잡히면 `SIG_Y1`, `SIG_MIN`, 색 기준. 서행에서 출발을 못 하면 `SLOW_BASE` 를 올림.

| 이름 (어디) | 처음 값 | 뜻 |
|---|---|---|
| `DARK_OFFSET` (ESP) | 40 | 그 줄 평균보다 이만큼 어두우면 라인 |
| `MAX_JUMP` (ESP) | 18 | 한 줄 위로 갈 때 라인 가운데가 이보다 많이 튀면 다른 물체 (칸) |
| `LOOK_Y` (ESP) | 42 | 향할 곳을 잡는 줄 (작을수록 멀리) |
| `CAM_SOFT` / `CAM_HARD` (ESP) | 20 / 50 | ±20 안 = `G`, ±50 안 = `L`/`R`, 그 밖 = `Q`/`W` |
| `CAM_LOST_MS` (ESP) | 300 | 라인이 이만큼 안 보이면 정지 |
| `SIG_Y1` / `SIG_MIN` (ESP) | 54 / 40 | 신호등을 보는 위쪽 줄 수 / 신호로 볼 최소 픽셀 수 |
| `FLASH_DUTY` (ESP) | 30 | 앞 LED 밝기 (0~255). 너무 뜨거우면 낮춤 |
| `SLOW_BASE` (버전 D) | 100 | 서행 기본 속도 (`MIN_PWM` 90 보다 커야 출발) |

버전 D 의 나머지 바퀴 힘은 버전 C 자동 주행 값(`BASE` 120, `KP` 51, `CORNER_OUT` 180 / `CORNER_IN` −90) 그대로. PID 기초는 [`PID.md`](PID.md).

## 10. 문제 해결

| 증상 | 확인 |
|---|---|
| `gulno-cam.local` 이 안 열림 | 폰·노트북이 **같은 핫스팟**인지. 뒤 빨간 LED 가 계속 켜졌는지. 시리얼 `I,ip,<주소>` 의 주소로 열기 (맥은 IPv6 때문에 이름으로 여는 게 나음). 안드로이드 일부는 `.local` 을 못 찾음 → 주소로 |
| 계속 설정 모드 (빨간 LED 천천히 깜빡) | 핫스팟이 켜져 있는지, **2.4GHz**(호환성 최대화)인지, 이름·암호가 맞는지. 시리얼 `I,fail` 이유 확인. 설정용 와이파이로 다시 넣기 (5장) |
| 핫스팟을 바꾸고 싶음 | 지금 핫스팟을 끈 채 ESP 를 켜면 15초 뒤 설정 모드 → 새 핫스팟 넣기 |
| 블루투스 **기기 찾기** 에 차가 없음 | 차 전원, HC-06 LED 깜빡(다른 기기에 안 붙음)인지. 폰 앱이 붙어 있으면 앱에서 끊기. 다시 찾기 |
| 블루투스가 붙었다 끊겼다 | ESP 와 차 거리, 전원 (5V 외부). 화면 "끊기" 후 "연결" |
| 주행 중 ESP 가 다시 켜짐 (영상이 끊겼다가 돌아옴) | 거의 **전원** : 5V 를 모터 배터리와 따로. 앞 LED `FLASH_DUTY` 를 낮추면 전류가 줄어듦. 시리얼에 `I,restart,low_heap` 이면 메모리 |
| 영상이 느림 | 컬러는 JPEG 라 느림 (초당 2~5장). 주행할 때는 **모폴로지** (숫자만 보냄). 화면을 2개 넘게 열지 않기 |
| 카메라 주행 버튼이 안 눌림 | 모폴로지 켜짐 + 차 블루투스 연결이어야 함 |
| 라인을 못 잡거나 바닥까지 잡음 | 9장 3번 (`DARK_OFFSET`), 카메라 각도, 앞 LED 반사 |
| 신호가 안 잡힘 | 폰 밝기 최대, 폰을 화면 **위쪽**에, 너무 멀지 않게. 9장 6번 |
| 빨간불에 서서 안 움직임 | 신호등 인식을 끄거나(ESP 가 `n` 을 보내 풀어 줌), 초록으로 바꾸거나, 정지·수동 → 라인센서 주행 |
| ESP 가 꺼졌는데 차는? | 5초 안에 차가 스스로 수동·정지 (연결 신호 `h` 가 끊겨서). ESP 를 다시 켜고 블루투스 연결, 또는 안드로이드 굴노 앱으로 HC-06 에 붙기 |
| 업로드 "Failed to connect" | MB 보드 IO0 누른 채 RST → 떼고 다시. 다른 USB 케이블(데이터용) |
| 시리얼에 `E,camera` | 카메라 리본 케이블을 뺐다가 끝까지 꽂고 잠금 |
| 다 초기화하고 싶음 | `~/.pio-venv/bin/pio run -t erase` 후 다시 업로드 → 저장된 핫스팟·블루투스·설정이 지워짐 (설정용 암호도 새로) |
